# Mon Métro Intelligent — application web

Prototype public de test, issu du projet privé MON_METRO_INTELLIGENT. Ouvrir `index.html` sur GitHub Pages après activation. Fonctions : GPS sur autorisation, détection de proximité de stations sur référentiel partiel et parcours simulés (lignes 1, 4, 14).

**Limites :** la reconnaissance d'une rame réelle et les horaires en temps réel ne sont pas encore intégrés. Aucun secret API ni document interne dans ce dépôt.
