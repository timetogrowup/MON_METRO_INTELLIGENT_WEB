Configurer le test Google de WENARE

Le pilote « Manger — complément Google » est prêt à configurer. Les transports et le catalogue habituel fonctionnent sans compte Google Cloud.

1. Créer le projet

  1. Ouvrez la console Google Cloud avec votre compte Google personnel.
  2. En haut, ouvrez le sélecteur de projet, puis Nouveau projet.
  3. Nommez-le WENARE-TEST. Conservez l'identifiant proposé par Google. Cliquez sur Créer, puis sélectionnez ce projet.

Si un écran diffère, revenez dans la conversation avec une capture, en masquant les informations personnelles et les clés.

2. Associer la facturation

Ouvrez Facturation et associez un compte de facturation. Google peut demander vos coordonnées et un moyen de paiement. Effectuez vous-même cette étape et l'acceptation des conditions.

Un quota gratuit ne garantit pas une facture nulle. Un budget déclenche des alertes, pas un blocage automatique. Dans Facturation → Budgets et alertes, créez par exemple une alerte à 5 € (ou l'équivalent dans la devise du compte), avec des seuils à 50 %, 90 % et 100 %.

3. Activer les deux services

  1. Dans API et services → Bibliothèque, activez Maps JavaScript API.
  2. Activez aussi Places UI Kit : ouvrir sa fiche officielle. Vérifiez que WENARE-TEST est sélectionné.

Ce pilote utilise le composant Places UI Kit Essentials, sans carte ni API Routes. Il ne faut pas activer toutes les API proposées. Si un quota de requêtes journalier est modifiable dans la console pour ce service, réduisez-le pour ce test ; ne comptez pas sur l'alerte budgétaire comme plafond.

4. Créer et restreindre la clé

  1. Dans API et services → Identifiants ou Google Maps Platform → Clés et identifiants, choisissez Créer des identifiants → Clé API.
  2. Nommez-la WENARE navigateur test.
  3. Restrictions d'application : choisissez Sites Web / référents HTTP. Ajoutez https://timetogrowup.github.io/*.
  4. Restrictions d'API : sélectionnez uniquement Maps JavaScript API et Places UI Kit. Enregistrez les restrictions avant le premier test.

Les navigateurs peuvent ne transmettre que l'origine du site à Google : une restriction au chemin du dépôt n'est pas fiable. Cette autorisation couvre donc votre domaine GitHub Pages. N'ajoutez pas de caractère joker sur tous les domaines.

5. Essayer dans WENARE

  1. Ouvrez WENARE, autorisez sa localisation, puis choisissez Manger.
  2. Dans Manger — complément Google, ouvrez Configurer mon test Google et collez la clé dans le champ prévu. Ne l'envoyez pas dans la conversation et ne la mettez pas dans GitHub.
  3. Choisissez votre rayon, lisez l'information de transmission à Google, puis appuyez sur Rechercher avec Google.
  4. Comparez les résultats habituels et Google. La recherche Google est limitée à 20 propositions ; les horaires ne prouvent pas une disponibilité.
  5. Utilisez Fermer le complément Google pour terminer. Aucune recherche n'est relancée automatiquement au changement de rayon.

La clé est conservée uniquement pendant cette ouverture. Il faut la saisir à nouveau après un rechargement complet. Le compteur WENARE compte les recherches lancées ici, pas les événements effectivement facturés par Google.

Tarifs et limites à vérifier avant activation

Au 8 novembre 2026, la grille Google affiche 10 000 requêtes mensuelles gratuites pour Places UI Kit Query (Essentials), puis 1 $ pour 1 000 au premier palier. Ce quota est partagé au niveau du compte de facturation pour cette référence tarifaire. Les composants avancés ont une autre tarification. Le pilote n'utilise pas ces composants avancés.
